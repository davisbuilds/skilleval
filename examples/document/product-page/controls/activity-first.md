# See your coding-agent work across projects

Keep active sessions and past conversations in view with AgentMonitor, a single-user local dashboard for Claude Code and Codex. Explore activity, search history, and compare token usage and estimated costs across your projects.

[See how to set it up](https://github.com/davisbuilds/agentmonitor#quick-start)

## A place to check what happened

AgentMonitor gives you session cards, searchable conversations, and usage charts without changing the history files your agents produce. Look through earlier tool calls, pin a useful moment, or inspect activity by project and model. Its command-line tool can return the same data as JSON when you want an agent to look up its own history.

Start on macOS or Linux with existing Claude Code or Codex history. Live activity takes optional hooks or telemetry configuration, and provider coverage differs: Claude Code gets the most detail, while Codex live activity is summarized and its transcripts come from session files. Cost figures are estimates and exclude unpriced models. The dashboard is local and intended for one user; optional insights and other documented features can make external requests. The setup guide covers prerequisites and the first run.
