# Find the coding-agent conversation you need again

AgentMonitor brings your Claude Code and Codex history into a local dashboard. Search past conversations, inspect tool calls, and follow token usage and estimated costs across projects from one place built for individual developers.

[Read the setup instructions](https://github.com/davisbuilds/agentmonitor#quick-start)

## Your agent history, within reach

When work spans several repositories, remembering which session holds a useful answer can take another search through terminal history. AgentMonitor reads the history your coding agents already keep and makes those conversations searchable. Browse tool calls and subagents, then pin moments you want to revisit. The original history files stay unchanged.

It runs locally for one user on macOS or Linux. Claude Code has the most detailed coverage; Codex transcripts come from session files, while its optional live telemetry provides activity summaries. Live monitoring needs additional hooks or telemetry setup. Usage charts show estimates, not a complete billing record. Start with the setup guide and your existing history; optional provider-backed insights and other outbound features have separate data-sharing considerations described in the README.
